CALCULATION ALGORITHM:
======================
Method: Newton-Raphson iteration
Parameters:
  - loanAmount: Loan principal
  - interestRate: Nominal rate (%)
  - termYears: Loan term
  - loanFees: Upfront closing costs
  - points: Discount points (%)

Formula:
  1. Calculate monthly payment from full loan amount
  2. Calculate total fees = loanFees + (points * loanAmount / 100)
  3. Net loan = loanAmount - total fees
  4. Solve for APR where PV(payments at APR) = Net loan
  5. Use Newton's method with convergence tolerance = 0.0001
  6. Round to 3 decimal places

Key Properties:
  - APR always >= nominal rate when fees > 0 (mathematically guaranteed)
  - Handles edge cases gracefully
  - Returns 0.000% if calculation fails (safe default)
