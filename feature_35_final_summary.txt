FEATURE OVERVIEW
==============================================================================

Feature #35 allows users to input loan parameters using natural language text
or voice commands. The feature uses Google's Gemini 2.5 Flash AI to parse
queries like "Payment for $350,000 loan at 5.5% for 30 years" and automatically
extracts and applies the relevant parameters to the calculator.

Key Capabilities:
• Text input with helpful suggestions
• Voice input with speech-to-text
• Supports 8 calculation types (payment, loan amount, term, rate, etc.)
• Extracts 12 different loan parameters
• Response caching for faster repeated queries
• Offline mode with request queue
• Secure API key storage
