Core Algorithm (amortization_service.dart:182-227):
------------------------------------------------------
1. Calculate monthly rate: interestRate / 100 / 12
2. For each month:
   - Calculate interest: balance * monthlyRate (rounded to cents)
   - Calculate principal: payment - interest
   - Adjust final payment to prevent overpayment
   - Calculate new balance: balance - principal
   - Round all values to cents
   - Stop if balance reaches zero early

Key Implementation Features:
- DecimalUtils.roundToCents() for precision
- DecimalUtils.ensureNonNegative() for safety
- DecimalUtils.isEffectivelyZero() for floating-point handling
- Early termination when loan paid off
